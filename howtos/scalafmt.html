Format Scala code with Scalafmt 🔗

Create .scalafmt.conf in the project root. For example, for Scala 3:

version = "3.10.7"
runner.dialect = scala3
maxColumn = 120

Use the appropriate dialect for your Scala version. Deder provides the fmt and fmtCheck Maven applications for Scala modules; you do not need to declare them in mvnApps.

Format a module's configured source directories:

deder exec -t runMvnApp -m mymodule fmt

To check formatting without changing files, for example in CI, run:

deder exec -t runMvnApp -m mymodule fmtCheck

The check fails if files need formatting. See the Scalafmt configuration reference for more options.
